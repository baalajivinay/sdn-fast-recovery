SDN Recovery Simulator

Replication of van Adrichem et al., EWSDN 2014

Recovery methods compared:

  • Restoration — Controller recomputes path after failure notification
  • Protection (LoS) — Pre-installed backup via fast-failover groups, triggered by carrier loss
  • Protection + BFD — Same as above but uses BFD probing to detect silent failures
  • Hybrid — BFD fast-failover + controller re-optimization of backup path

Nodes: Red circles = hosts (endpoints) · Blue rectangles = OpenFlow switches · Yellow circle = SDN controller

Model-based simulation calibrated against published results. Time scaled for visibility.
